# Kitchen Timer

A simple browser-based kitchen countdown timer.

## Features
- Set minutes and seconds
- Start, pause and reset
- 3-minute tea preset
- 10-minute rice preset
- 20-minute preset
- Alarm sound when the timer finishes
- Mobile-friendly design

## Run locally
Open `index.html` in a web browser.

## Deploy
This project can be uploaded to GitHub and deployed on Vercel as a static site.
